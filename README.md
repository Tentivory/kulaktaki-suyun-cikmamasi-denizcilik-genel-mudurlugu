# kulaktaki-suyun-cikmamasi-denizcilik-genel-mudurlugu
Duştan sonra kulakta kalan suyu resmi kabotaj ihlali, milli kulak egemenliği ihlali ve iç deniz protokolü sapması sayan; pamuğu römorkör, 'kafamı sallarsam çıkar' cümlesini seyir defteri ilan eden Genel Müdürlük. Gerçekten çalışır. Kulaklar artık limandır.
